# Reference photographs (not committed)

Place the 9 reference photos here as `tai_01.jpg` … `tai_09.jpg` before running `npm run generate:references`.

- 01–04: soft layered black hair, blue striped shirt, burgundy sweater, oversized charcoal coat
- 05–09: black layered hair, dark formal outfit, deep-red glitter detail

They are third-party photographs used only as local input for the Tripo image-to-image step. They are git-ignored
and are never copied to the website. The pipeline caches their content hashes, so generated assets stay valid
without them; you only need them to regenerate the master reference.
